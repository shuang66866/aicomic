# AI漫剧视频制作工作台

一个从想法到成片的 AI 漫剧视频制作工具。你只需要提供故事想法，剩下的交给它——AI 帮你写剧本、设计角色和场景、生成分镜图与视频、配音、合成最终视频。

## 制作流程

```
剧本创作 → 角色场景 → 分镜设计 → 视频合成
```

四步走完即可产出一条完整的漫剧视频。每一步都可以随时回头修改，流程支持反复迭代。

## 功能一览

### 项目概览

- 创建和管理多个项目，每个项目独立存储、互不干扰
- 项目状态追踪：草稿 → 剧本中 → 角色中 → 分镜中 → 生成中 → 已完成
- 上传项目封面，一目了然地识别项目
- 四步流程引导，随时点击跳转到任意环节

### 剧本创作

- 填写故事大纲，选择故事类型（古风仙侠、现代都市、科幻未来、悬疑推理、爱情甜宠、历史传奇）
- 一键 AI 生成剧本，自动拆分为场景列表
- 直接粘贴一段文本，AI 自动帮你拆分成场景
- 场景拖拽排序、批量删除
- 剧本生成后，可一键跳转生成分镜

### 角色场景

- 添加角色和场景，AI 一键生成形象图
- 支持上传参考图，AI 按参考图风格生成
- 角色/场景图片支持多版本切换，不满意可以随时重新生成
- AI 批量生成提示词，省去逐条编写的时间

### 分镜设计

- 每个分镜卡片包含：图片/视频媒体区（Tab 切换）、AI 生图、AI 生视频、AI 配音
- 图片生成：支持重新生成，不覆盖原图，历史版本随时可查
- 视频生成：支持参考图片、台词同步口型
- AI 配音：支持配音、旁白、对话多种标签
- 批量操作：全选、批量删除、自动关联角色场景、AI 批量提示词、批量生成图片/视频/配音
- 通用生成设置面板：比例、分辨率、时长等参数统一管理
- 分镜拖拽排序，布局自由调整

### 视频合成

- 多轨时间线编辑器：视频/图片片段轨道、音频轨道（含波形显示）、字幕轨道
- 片段支持拖拽排序、时长调整、转场标记
- 字幕支持编辑与选中，方便逐条校对
- 右侧属性面板随时查看和修改片段/字幕/音频参数
- 视频预览区，合成前先看效果
- 一键合成导出最终视频

### 无限画布

- 节点式工作流编辑器，自由搭建 AI 创作管线
- 10 种节点类型：文本、AI 文本、图片、AI 生图、AI 图片编辑（局部重绘 + 扩图）、视频、AI 生视频、参考图库、AI 配音、正向/负向提示词
- 节点间连线传递数据，类型匹配约束，操作直观
- 局部重绘：画笔/矩形选区/橡皮擦标记遮罩，AI 精准修改局部
- 扩图：选目标比例和分辨率，AI 自动扩展四周
- 无限平移、缩放（0.2x~3x）、框选多选、拖拽布局、右键快速创建节点
- 剪贴板复制粘贴节点组、撤销栈
- 画布布局随项目保存，随时回来看

### 智能 Agent 对话

- 内置 AI 对话助手，用自然语言辅助创作
- 支持流式输出，边等边看结果
- 对话记录自动保存，随时回看、继续对话
- 提示词优化：把粗糙的描述丢给它，帮你改得更精准

### 模型管理

- 添加和管理 AI 模型（图片生成、视频生成、TTS、LLM）
- 支持主流服务商：MiniMax、DeepSeek、OpenAI、Stability AI、Runway、Pika 等
- 连接测试，确认配置正确
- 启用/禁用、编辑模型配置

### 生成队列

- 查看图片/视频生成任务的排队与执行状态
- 图片最大并发 10 个，视频最大并发 1 个
- 任务状态实时显示：待提交 / 提交中 / 生成中 / 完成 / 失败
- 随时取消排队中的任务

### 历史记录

- 查看所有历史生成记录
- 一键清除，释放空间

### 导出

- 合成最终视频（自动安装 FFmpeg，无需手动配置）
- 导出到剪辑软件

### 设置

- 数据存储位置配置
- 自动保存开关
- 默认模型设置

## 使用前需要准备什么

1. **AI 模型密钥**：在「模型管理」里添加你的 API 密钥（图片、视频、TTS、LLM 各选一家即可）
2. **视频合成**：合成最终视频需要 FFmpeg，缺省时应用会自动帮你安装，不用手动操心
3. **数据目录**：默认存在 `D:\AgentWork`，自动创建，不用选路径

## 数据存储

- 所有数据（项目、剧本、分镜、图片、视频、对话记录）全部保存在本地，不依赖任何服务器
- 有 D 盘时默认数据目录为 `D:\AgentWork`（自动创建）
- FFmpeg 安装在 `D:\AgentWork\ffmpeg`

## 自动更新（桌面版）

- 点击左下角版本号即可检查更新
- 检测到新版后询问是否下载，带实时进度条
- 下载完成后自动重启安装，无需手动操作
